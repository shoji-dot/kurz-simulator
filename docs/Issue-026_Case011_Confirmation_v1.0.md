## 新原則(case-001決定、shoji確定)の適用

`docs/Issue-026_Ossicular_Procedure_Classification_Audit.md`で確定した原則:

> 「ツチ骨柄残存＝II型」という簡略基準は廃止し、今後は再建経路（接続先）を基準に分類する。

この原則をcase-011のclinicalNotesに適用すると、以下の再建経路が読み取れる。

```
術前: incus partial(キヌタ骨長突起の部分骨吸収、まだ残存)
  ↓
術中: 「キヌタ骨長突起残存部は除去してPORP頭板の支持面を確保する」
  ↓
術後の実際の再建経路: ツチ骨柄(TM/malleus handle) → PORP → アブミ骨頭部
```

**観察(判断は加えていない)**: 術前はincus partial(部分残存)だが、clinicalNotes記載の通り
**術中にその残存部を除去してPORPを設置**しており、最終的な再建経路はcase-001/008と同じ
「ツチ骨柄→PORP→アブミ骨頭部」になっているように読める。この経路はJOS2010のⅢi-M
(アブミ骨-ツチ骨間再建)に相当し、Ⅱ型(キヌタ骨上に鼓膜を形成する、プロステーシス非使用)の
定義とは一致しないように見える。

## 確認したい点

上記の読み取りが正しければ、case-011のtags.procedureも「II型」→「III型」への修正が
妥当と考えられる。ただし以下の点で判断が割れる可能性があるため確認したい。

1. 「キヌタ骨長突起残存部は除去して」という記載は、**支持面確保のための部分的な整形**であり、
   キヌタ骨長突起自体は完全除去されず一部が再建経路に関与し続ける可能性はあるか
   (この場合、Ⅲi-Iまたは異なる分類になる可能性)。
2. description・teachingPointsが「II型」という分類を、**病態(キヌタ骨長突起の骨吸収パターン)
   の呼び名**として使っている可能性はあるか(すなわち、実際の再建経路の分類ではなく、
   臨床像の分類として「II型」を使っている場合、case-001とは性質が異なる論点になる)。
3. 上記いずれであっても、tags.procedureの表記は再建経路を反映すべき(shoji確定の原則)と
   考えてよいか。

**回答欄**:

```
1. 無い。
2. 使っていない。
3. 良い。
```

## 実装内容(完了)

`src/data/cases.ts`のcase-011を以下の通り修正。

- `title`: 「症例11: 小児慢性中耳炎 — PORP（II型 小児）」→「症例11: 小児慢性中耳炎 — PORP（III型 小児）」
- `description`: 「鼓室形成II型の適応」→「鼓室形成III型の適応」
- `teachingPoints[0]`: 「…骨吸収が最多パターン（II型）。…」→「…骨吸収が最多パターン（III型）。…」
- `tags.procedure`: `['鼓室形成II型', 'PORP', '軟骨グラフト']`→`['鼓室形成III型', 'PORP', '軟骨グラフト']`

検証は`ts.transpileModule`による構文チェック(診断0件)を実施(Issue-027/Issue-026 case-001と
同様、プロジェクト全体のBuild/Lintはsandbox環境のI/O速度により今回も未完了)。

## (参考)修正した場合の影響

case-001と同様、`tags.procedure`・`title`(該当があれば)・`description`の該当箇所のみの
文字列修正で完結する見込み。teachingPoints[0]の「（II型）」という記載も、修正する場合は
対象に含める必要がある(case-001では該当なしだったが、case-011は該当あり)。
