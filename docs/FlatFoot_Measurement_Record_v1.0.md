## 1. 追加で必要な測定項目

以下を20倍模型でノギス実測し、20倍模型実測値の列に記入してください(実寸換算はこちらで
計算します)。可能であれば各項目に加えて、写真(複数方向)があると形状確認の助けになります。

| # | 項目 | 20倍模型実測値 | 実寸換算(÷20) | 備考 |
|---|---|---|---|---|
| 1 | 天井(シャフト接続部側)の外径 | **(未測定)** | | 開口部から見て一番狭い/シャフトに近い側の外径 |
| 2 | 天井(シャフト接続部側)の内径 | **(未測定)** | | 中空(ボア)が天井まで貫通しているか、途中で閉じているかも合わせてご確認ください(§2 Q1) |
| 3 | テーパー開始位置(開口部からの高さ) | **(未測定)** | | 開口部(高さ0)から測って、テーパーが始まる高さ。全高が一様にテーパーしている場合は「0」または「該当なし」とご記入ください |
| 4 | テーパー角(軸に対する角度) | **(未測定)** | (角度なので÷20不要、そのまま) | 測定が難しい場合は#1・#3・全高(0.8mm)から幾何学的に算出できるため、無理に測定いただかなくても構いません |

| 6 | シャフト接続部の径 | **(未測定)** | | #1(天井外径)と同一の場合は「#1と同じ」とご記入ください。別に細いシャフト連結部がある場合はその径 |

## 2. 確認事項(定性、Yes/Noまたは簡単な説明で可)

1. **中空(ボア)は天井まで貫通していますか、それとも途中(または天井)で閉じていますか?**
   (カタログ記述「cannulated distal footing」から、下面から入った流体が保持される構造を
   想定していますが、天井側が完全に閉じているのか、細い穴として貫通しているのか未確認です)
2. **テーパーは直線的ですか、それとも曲面(丸み)を帯びていますか?**
3. **面取りは天井の外周エッジのみですか、それとも内周(ボア側)にもありますか?**
