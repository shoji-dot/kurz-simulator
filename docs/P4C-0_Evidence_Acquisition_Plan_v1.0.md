# P4C-0: Evidence Acquisition Plan(Head Plate Normal取得手段の実現性調査) v1.0

**Status**: Blocked / Deferred
**位置づけ**: 必要なEvidence条件(§3 不足データ)は本文書で定義済みだが、取得手段が確定して
いないため、P4C本体(composeNormal()実装)は取得手段確定まで実装保留とする。P4C-0自体は
コード変更を伴わない調査・方針文書として本版で凍結する(2026-07-29、shojiさん承認)。

## 1. 背景(なぜP4C-0が必要か)

P4Cで採用予定のEvidence取得方法(Open3D/TrimeshによるPlane Fit)は、入力として3Dメッシュ/
点群を必要とする。しかし調査の結果、以下が判明した。

- `kurz-simulator`リポジトリ内`3D_scans/`はOpenEar側頭骨解剖モデル(subj_A〜T.stl、耳小骨・
  内耳)のみで、KURZ PORPヘッドプレート自体の3Dスキャン/CADは存在しない。
- Dropbox「モデル」フォルダも製品カタログPDF・写真・動画のみで、メッシュ/点群ファイル
  (stl/obj/glb等)は存在しない。
- `docs/P4A_Geometry_Validation_Report_v1.4.md`(⑤⑥⑦節)によれば、既存の多視点写真から
  3D復元を試みる手法(特徴点対応・PnP・Visual Hull・三角測量)は**「本写真条件では実施不能」**
  と結論済み。原因は各写真に回転角度のラベル(各写真がどの軸を中心に何度回転させたものか)が
  付いておらず、カメラ姿勢を写真自体から独立に確定する手段がないこと。

したがって「Plane Fitのアルゴリズム」ではなく「入力となる3Dデータが存在しない」ことが
現時点のボトルネックであり、P4Cを実装から始めると同じ壁に再度ぶつかる可能性が高い。

## 2. 現状(利用可能なデータの棚卸し)

| データ | 内容 | Evidence該当性 |
|---|---|---|
| 拡大PORP模型の多視点写真(10枚+8枚) | P4A-1/A-2で撮影・cv2計測済み(ルーラー較正、約20倍) | Origin/X/Y軸はEvidence A(確定済み)。Z軸には使用不能(上記理由) |
| ノギス実測値 | ボス偏心量等、一部の値 | Evidence A+(実物直接計測)。角度データは未取得 |
| KURZ製品カタログ(PDF) | 外形図・寸法表(Dropbox「モデル」フォルダ) | 角度情報の有無は未確認(要確認、本文書§4-②) |
| OpenEar STL(3D_scans/) | 側頭骨解剖(耳小骨・内耳)のみ | Head Plate Normal取得には無関係 |

## 3. 不足データ

Head Plate Normal(Z軸)をEvidence A以上で確定するには、以下のいずれかが必要。

1. PORPヘッドプレートの3Dメッシュ/点群(新規3Dスキャンまたは製造元CAD)
2. カメラ姿勢(回転角度)が既知・ラベル付けされた多視点写真セット(新規撮影)
3. ノギス等によるHead Plate面とShaft軸の直接角度計測(治具が必要、現状未実施)

## 4. 各取得方法の実現性評価

### ① 新規3Dスキャン(物理アクション)

- **精度**: 高(スキャナ精度に依存、一般的な民生スキャナ/スマホアプリでも0.1〜数百µmオーダー)
- **Evidence区分**: A+(実物直接計測に準ずる)
- **コスト/工数**: 中〜高。拡大模型のサイズ・材質(反射・透明部材の有無)によりスキャン難易度が
  変わる。スマホの構造化光/LiDARスキャンアプリで試すのが最も低コストな第一歩。
- **リスク**: 拡大模型の材質(金属・光沢面)によってはスキャンが失敗しやすい(光学スキャナは
  鏡面反射に弱い)。マット塗装やスプレーでの反射低減処理が必要になる可能性。
- **shojiさんの実作業**: 必要(模型のスキャン実施)。

### ② KURZ公式CADデータの問い合わせ

- **精度**: 最高(製造元設計データそのもの)
- **Evidence区分**: A+(最も信頼性が高い)
- **コスト/工数**: 低(問い合わせのみ)だが、提供可否・NDA・回答期間が読めない
- **リスク**: 提供されない可能性、提供されても角度情報が本プロジェクトの座標系定義と
  異なる基準で記述されている可能性(すり合わせが必要)
- **shojiさんの実作業**: 必要(KURZ社への問い合わせ)。並行して進める価値は高い(コストが
  低いため、①③と並行して着手できる)。

### ③ 新規写真セットでの多視点復元再挑戦

- **精度**: 中(条件次第でEvidence Aまで到達可能)
- **Evidence区分**: 条件が整えばA、整わなければ従来同様「実施不能」に終わるリスクあり
- **コスト/工数**: 中。P4Aの失敗原因(角度ラベル欠如)はターンテーブル+既知の角度刻みで撮影
  すれば解消できる可能性が高い(原因が特定されているため、闇雲な再挑戦ではない)。
- **リスク**: 「前回と同じ条件」での再撮影は無意味(v1.4の教訓)。ターンテーブル・固定カメラ・
  既知角度刻み・十分な枚数・マーカー(スケール較正用)を撮影設計に組み込む必要がある。
- **shojiさんの実作業**: 必要(撮影環境の準備・実施)。

## 5. 優先順位(2026-07-29、shojiさん最終判断)

技術的な優劣(§4)とは別に、プロジェクトの現段階(プロトタイプ開発中)を踏まえた判断として、
以下の優先順位とする。

- **② KURZ公式CAD/STL問い合わせ**: 技術的にはEvidence A+として最有力だが、社内承認・KURZへの
  正式依頼プロセスを要する。現時点(プロトタイプ段階)で問い合わせるより、アプリの完成度を
  高めたうえで正式提案・相談する方が成功率が高いと判断し、**中長期の正式相談項目へ格下げ**
  する(最優先タスクとしては扱わない)。
- **① 新規3Dスキャン**: 正式なEvidence取得プロジェクトとして今すぐ開始する必要はない。ただし
  低コストな実現性確認(スマホの簡易スキャンアプリ等で対象形状が取得できるかを試す程度)は、
  §6の優先タスクと並行して検討してよい。
- **③ 新規写真セットでの再撮影**: 現時点では着手しない。①②の実現性確認・正式相談が難航した
  場合のバックアップとして保留する。

## 6. 次フェーズの開発優先度(P4C-0凍結にあたっての方針)

P4C本体(composeNormal()実装)はHead Plate Normal Evidence取得後に開始することとし、それまでは
以下を優先する(2026-07-29、shojiさん方針)。

1. **PORP/TORPプロステーシスモデルの品質向上**: 現行モデルは機能上動作しているが、教育用途
   としての外観・製品再現性には改善余地がある。Blender導入も含めたGeometry品質向上を検討する
   (`Blender Policy`が対象とするのは「Blender MCP経由の計測・幾何解析」であり、モデル品質
   向上のためのBlender活用は別軸の検討として扱う)。
2. **Ground Truth collectionの継続**: 実測データ・配置データ・症例データの蓄積は、AI Tutor・
   Case Generator・Skill Trackingにも影響するため重要。
3. **UI/教育体験の改善**: 外科医が使用する教育ツールとしての操作性・理解性を向上させる。
4. 上記と並行して、KURZ公式CAD提供可能性についての社内準備(§5)を進める。
